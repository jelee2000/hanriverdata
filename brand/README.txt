HAN RIVER DATA — BRAND KIT
Version 1 / 12 October 2026

THE MARK
Two angular riverbanks frame an open, gently curved channel.
Use this exact mark consistently; preserve the space between the banks.

FILES
mark.svg / mark-reversed.svg: standalone scalable symbols, tightly cropped.
wordmark.svg: outlined lowercase wordmark, tightly cropped.
logo-horizontal*: tightly cropped symbol + wordmark, transparent.
logo-square*: 1024 x 1024 profile icons with safe margins.
logo-banner*: 2000 x 600 horizontal logos with safe margins.
logo-stacked*: 1024 x 1024 square compositions with mark and name.
social-preview*: 1200 x 630 website sharing card.
brand-sheet*: 1600 x 1240 visual overview.

SVG files are scalable, editable vector artwork.
PNG files are ready to upload. Files named transparent have an alpha channel.
Reversed versions use ivory artwork for dark backgrounds.
The logo wordmark is outlined so it does not require installed fonts.

COLORS
Charcoal: #252723 / RGB 37, 39, 35
Warm ivory: #f7f6f2 / RGB 247, 246, 242
Supporting gray: #62655e / RGB 98, 101, 94

TYPE
Lowercase, neutral sans serif. The logo uses outlined Helvetica Neue Regular.
The website retains its existing system font stack:
-apple-system, BlinkMacSystemFont, "Helvetica Neue", Arial, sans-serif.
No font files are included in the kit.

USAGE
Use charcoal on light surfaces and ivory on dark surfaces.
Leave at least one quarter of the mark's height as clear space around it.
Square and banner files already include suitable margins.
Use the mark alone at small sizes; retain the open river channel.
Do not stretch, rotate, outline, add effects, or change the proportions.
Use SVG when resizing; use the PNG exports for social profiles and documents.
